# Peasant Swarm — Build Spec v3 (approved by Peter 2026-09-24; his direction is the contract)

Extends the v2 spec (`repos/games/peasant-swarm/SPEC.md`, cited as "SPEC-v2 §n"). Everything in v2 stays as shipped unless a section here changes it. Research: `game-research/peasant-swarm-v3/` (R1–R4, C1, C2, `synthesis.md`). Every number here is a starting value and lives in `config.json` with a `_units` entry range-checked by `PS.selfTest`. Code comments cite this file as "SPEC-v3 §n".

## 0. Rules for builders

SPEC-v2 §0 in full, plus:
- **Kill switches.** Every v3 system has a config switch (`fog.losWalls: "off"`, `forest.on`, `structures.enabled`, `units.enabled`). Sight and forest switches restore v2 exactly. `structures.enabled: false` restores v2's villages and bandit camps but not heavy chests (their code is gone, §3); the regression bar for M3a/M3b is the documented tier-supply delta, not literal v2 parity. At every milestone the harness runs the v2 pacing table with whichever switches exist by then turned off together.
- **Determinism split.** A sim-visible event (does a rustle fire this tick, does a stockade shoot, which agent an archer targets) is plain arithmetic on tick state or `S.rng`. `Math.random` only decides pixels (rustle jitter offset, particle spread). A builder who is unsure writes it on `S.rng`.
- **One winner, tie-broken by agent id** wherever a scan over the neighbour hash must pick one agent. No `Map`/`Set` iteration in a hot path.
- **Whole-tick bench gate per milestone** (§9). A component estimate is not acceptance.
- **Fog honesty.** Every new sight source, knowledge read and objective list goes through the existing `vis`/`kn`/`sk` gates (SPEC-v2 §5, §7). The leak check stays at 0.
- **Pacing numbers are M5 tuning targets, not milestone acceptance bars**, except where §9 says otherwise. A milestone gates mechanism and cost; M5 gates feel.

## 1. What v3 is

Same promise, same pillars, same 5:00 match. Four additions and one subtraction:
1. **Ground that hides.** Cliffs block sight. Forests hide whoever stands in them. Small swarms and remnants can disappear; the leader cannot (a grove hides about 150).
2. **Buildings that change hands.** A joined village keeps working for its owner (mill). A cleared bandit camp becomes a tower with sight (stockade). Three forges sell relic tiers for peasants. Win a fight next to a building and it is yours.
3. **Archers.** Hold a stockade and a share of your new recruits carry bows. They shoot from the back ranks at a slowed or waiting enemy: a column wading a ford, a column queued in a pass.
4. **Portal-ready.** A build that runs on CrazyGames (and Poki) with the SDK, self-hosted fonts, and a phone that never loses vision to a performance tier.
5. **Subtraction.** Heavy chests (the forge replaces them), the Armor and Frenzy orbs, the third muster milestone.

No gold. The swarm is the purse. Player-facing system count: v2 17, v3 19–20 (C1's table). 21+ reopens the spec.

## 2. Terrain that hides (M2)

- **Two layers**, placed after the fairness pass so path distances, fairness ratios and rerolls are exactly v2's: `opaque` Uint8 (1 = blocks sight; every rock cell when `fog.losWalls` is "all"; water never) and `cover` Uint8 (1 = forest). No new `terr` code: forests do not change walkability. `placementOk` gains `!cover[c]` (camps, trickle, objectives never in forest).
- **Sight rule.** A cell is visible if the source has clear line of sight to it. A forest cell is visible only if it also lies within `forest.seeInto` 96 px of one of your sources; otherwise it is "in sight, concealed": you see the tree line, not what stands in it. Forest cells block sight through them (`forest.blocksSight`). Hiding is per agent per cell: the visible part of a half-hidden swarm is what you see, and the ghost, arrow and clash panel use that visible count. Pips stay live (SPEC-v2 §5). The YOU chip shows a leaf mark while ≥ `forest.hideShare` 0.5 of your agents stand in forest.
- **Viewshed.** Symmetric shadowcasting on the 128-grid, integer slopes, no `Math.sin/cos`. Two caches keyed by source cell, cleared per map: centroid viewsheds at `fog.losMaxCells` 30, bucket viewsheds at `fog.losBucketCells` 8; 2 bits per cell (hidden / clear but forest-concealed / clear); cap `fog.losCacheCells` 2048 centroid entries then clear all. A hit and a miss give identical bits (pure function of static terrain and source cell), so replays never depend on cache history. `fog.losWarmIris` true warms spawn and pass cells during the iris. Stamp: `vis = v` for clear and for concealed-within-seeInto, `vis = v + 1` for concealed, skip hidden; versions step by 2 so `sees()` keeps its single compare. Skip the shadowcast entirely when the source is farther from any opaque cell than its radius (precomputed chamfer distance to opaque, one pass at gen).
- **Reveal.** Proximity (seeInto). Fighting: each engagement's contact point inside your sight and LOS but in concealed forest lights forest cells within `forest.fightReveal` 96 px for `forest.fightRevealSeconds` 2. Rustle: an enemy agent standing in a concealed cell you otherwise see makes leaves shake at a jittered point every `forest.rustleEvery` 2 s per rival, offset ≤ `forest.rustleJitter` 64 px, no count, never behind rock. **The rustle event is sim state** (which rival, which tick: arithmetic on the tick counter); only the pixel offset is `Math.random`. **The rustle has a sound**: a short leaf hiss on the low-priority cue budget, gated like every tell. Dust and clash noise unchanged; a hidden 150 still raises dust.
- **Movement.** `forest.speed` 0.9, `forest.cost` +4 per forest cell in the flow cost. No colliders.
- **Placement.** River reeds: `terrain.forest.bankWidth` 2 cells each bank, 1D-noise-masked to `bankCover` 0.7, kept `bankClear` 3 cells from crossings, none in the central meadow. Groves: `grovesPerRegion` 2 per spawn region, `groveCells` [25, 45] each, seeded flood fill on noise; ≥ `groveMinFromHome` 6 cells outside the home wall, never in `passMask`, ≥ `groveClear` 4 cells from any chest, village, bandit camp or power-up site, sdf ≥ 1 cell, never in the central meadow; seed cells preferred between home exits and passes so groves flank routes. Fairness: grove area per region max/min ≤ `terrain.forest.fairRatio` 1.3, same count per region; failure reshuffles grove seeds (`terrain.forest.tries` 8), never a map reroll. About 700 of 16,384 cells.
- **Ambush.** No combat bonus. The local rout rule (SPEC-v2 §6) already pays for position. Measure `fixture_grove_ambush` over 8 seeds before considering one.
- **AI.** Fog-honest as before; the viewshed feeds the same `vis` grid. `ai.forestFleeBonus` 150 px-equivalent for forest cells in the flee score (remnants run for trees). `ai.rustleMemory` 3 s: a rustle an AI saw counts as an unknown threat for camp avoidance. Sly `lurkForest` true: lurks in the grove nearest its pass. AI never hunts what it has not seen: `ai_blind_in_grove` asserts it.
- **Render.** Rock shadow (`fog.shadowAlpha` 0.55) and forest shade (`forest.shadeAlpha` 0.25) as a shadow texel canvas composited into the existing fog canvas at ≤ `fog.shadowHz` 15 before its single blit. Still exactly one full-screen alpha draw. Forest art: baked dark canopy in the ground chunks plus a ring of edge tree sprites (no collision, 10–15 draws per screen), readable at zoom 0.5 on 375 px.
- **First-sighting lever.** Measured sim-only over 40 seeds before any forest art (§9). Companion levers only if the probe needs them: `powerups.firstDelay` 30 s (0 = v2), `ai.siteKnowRadius` 1000 px (0 = v2, all sites known).
- **Deferred:** tall grass as a hide-only type, canopy over units, height sight, watchtowers, ambush bonus, `forest.dustHush`, AI investigating a rustle, lures inside groves.

## 3. Structures (M3a plumbing, M3b forge + stockade)

One rule set. Sites are landmarks (AIs know where, never the state; players learn them through fog). Mill and stockade are **states of the village and bandit-camp objects v2 already has**, not new object types. Forges are three new sites.

- **Capture by ring hold** (the v2 village rule, SPEC-v2 §8): have ≥ need in the 100 px ring and the site flips; with fewer, the timer runs `1.2 s × (need − have)`, 2 s minimum; any other team's agent in the ring pauses it; remnants in their window never count. Need on an owned site = `max(structures.guardMin 6, banked)` for a mill, `structures.stockade.captureMin` 8 for a stockade. The ring shows the number a rival needs; your own ring shows your banked count in your colour.
- **Rout flips structures.** A rout whose contact centroid lies within `structures.routFlipRadius` 300 px of a site owned by the loser hands it to the winner. **Elimination** (`structures.neutralOnElim` true) returns a team's sites to neutral with bank 0.
- **Fog.** Owner and banked count are last-seen state (`sk.team`, `sk.n`). An AI knows its own sites live and may target a rival-owned site only if it has seen that owner there.
- **Mill** (M3a). A village that has joined keeps working for its joiner: sails turn, owner pennant. Banks +1 recruit every `mill.every` 6 s up to `mill.cap` 12 (a counter, not hidden agents). Collect: ≥ `mill.collectMin` 3 owner agents in the ring for `mill.collectHold` 0.5 s; the bank walks out of the gate through `convert()` (muster counts, agent cap respected, excess stays banked). Walking through collects. Raid: a captor takes the bank. Flat output (+12/min per mill) so it compounds weakly, costs a route and can be raided. About 20–40 peasants per owner per match.
- **Forge** (M3b). `forge.count` 3, one axis each (Arms, Boots, Horn, shuffled per match), on the ring at `forge.ringR` 0.24 W between spawn pairs, icon once explored, no owner. Price in peasants for the team's next tier: `forge.prices` [20, 40]; sells to tier II only (Arms III stays red camp or leader drop). **Intent rule** (`forge.needTarget` true): sells only when the team's route target is inside its ring (tap, resting cursor, AI target) and ≥ price agents stand in the ring for `forge.hold` 1.5 s. A swarm routed past never pays. **Floor** (`forge.minShare` 0.5, from C1): never sells if paying would leave the team under half its current count; the ring then shows the price greyed with "too few". Pay: the nearest `price` agents file into the door over `forge.payWalk` 1 s (render walk, then swap-removed), then `grant()`; banner "ARMS II · 40 PAID". `forge.shareFloor` 0 (leader tax lever, off).
- **Stockade** (M3b). A cleared bandit camp becomes a stockade owned by the team that landed the last hit (`o.lastHit`). Six: 3 green, 2 orange, the red one at the centre. Fires every `stockade.every` 0.9 s at the nearest rival agent (teams 1–6, not owner, neutrals, bandits or remnants) within `stockade.range` 200 px, engaged agents first, `stockade.damage` 3; off until `stockade.activeAfter` 60 s. Sight: owner stamps `stockade.sight` 450 px around it (one more stamp source, obeys §2). Capture by ring hold with no owner agents in the ring; the stockade shoots while you take it. Not a team: never enters engagement pairs, cannot trigger a break by itself; its kills cut the victim's rout-group survivors inside a clash (bounded, about 3 kills in 10 s). Kills never convert. Arrows: fixed pool `stockade.arrowPool` 16, drawn only when `playerSees`.
- **`trains` hook.** Each structure kind has `trains: {type, share} | null`. While you own it, `share` of each new neutral recruit (not absorbed rivals) arrives as that type, capped per team at `units.maxShare`. v3 map: `stockade.trains = {type: "archer", share: 0.2}`; mill and forge `null`.
- **AI** (M3b). Structures enter `aiPick` as objectives: `ai.objMill` 40 per banked recruit, `ai.objForge` 300, `ai.objStockade` 280. AIs buy only when `count ≥ price × (1 + ai.forgeReserve 2.0)`. Collect at `ai.millCollectAt` 10 (Greedy 6). Rival-owned stockade ranges join the forage avoid list (`campAvoidRadius`). Per-personality `structBias {mill, forge, stockade}`: Greedy 1.6/1.0/0.8 (collects at 6 within 700 px, chains mills), Bully 1.0/1.0/0.8 (raids the player's mills it has seen; second use for scent), Wary 1.0/1.0/1.2 (collects only with no clash heard within 800 px; flees toward its own stockade), Sly 1.2/1.0/1.0 (lurks at a rival-owned mill; steals mills whose owner was last heard fighting > 800 px away; takes stockades whose owner fights elsewhere), Stubborn 1.0/1.0/1.5 (its claimed site becomes its mill or stockade; holds 350 px). `forgeAxes` order per personality: Greedy Horn > Boots > Arms; Bully Arms > Boots; Wary Boots > Arms; Sly Arms > Horn; Stubborn Arms > Horn.
- **Removed / changed.** `encampments.heavy*`, `ai.objHeavy` removed; the `heavy` branch of `spoils.js` becomes the forge branch. `progression.muster` [50, 200], `musterAxes` ["horn", "boots"]. `powerups.weights.armor` and `.frenzy` 0 (keys kept). Fixed chests, trickle chest, bandit relics, leader drops unchanged.
- **Deferred:** gold, build spots, forge pick-1-of-2, structure upgrades, double-rate mills after the horn, crowned team's structures on every minimap, a barracks object, `forge.shareFloor` > 0.

## 4. Archers (M4)

One type. Knights and tool racks are cut (C1).

- **Kind.** `a.kind` Uint8 (0 peasant, 1 archer) and `a.shotT`, both initialised in `mkAgent`. Source: the `trains` hook only (§3). Recruits, muster, villages, garrisons and mill banks are peasants unless a `trains` hook says otherwise.
- **Melee.** An archer in melee is a weak peasant: damage × `units.archer.melee` 0.5, hp × `units.archer.hp` 0.8. No formation code; boids mix archers through the swarm, so most stand behind the frontage.
- **Volley.** Per-archer timer `units.archer.interval` 1.6 s, jitter 0.8–1.2 on `S.rng`. When it expires and the archer is not in melee and its team is either engaged or moving under `units.archer.fireTeamSpeed` 0.35 × its pace, the archer does ONE gather at `units.archer.range` 140 px, picks the nearest enemy (team or bandit; never neutral, never a remnant; ties by agent id) and writes a pending hit into a fixed pool of `units.archer.maxArrows` 192 (typed arrays). Landing after `units.archer.flight` 0.45 s: skip if the target is dead, escaping or has flipped to the source team; else `units.archer.damage` 1.5, kill credited to the source team. Homing, no misses. Arrows alone never start an engagement, so arrows never rout anyone: they soften, melee breaks.
- **Rout and absorb.** Flipped archers keep their bows (`units.flipKeepsKind` true; hp resets to the new team's max × kind hp). Remnants keep kind and cannot shoot. Finale scatter to neutral resets to peasant (`units.scatterResets` true). No typed drop from a routed leader.
- **Power.** `power = armsPower[tier] × (1 + share_archer × (units.archer.power 1.35 − 1))` at recount, so AI hunt/flee ratios and the clash verdict see archers. Set by harness parity (§9), the way M6 set `armsPower`.
- **Readability.** Type on the body and weapon, never the hat: bow instead of pitchfork, arrows in flight (draw cap `units.archer.drawArrows` [32 touch, 64 desktop]). One `drawImage` per agent (kind selects the atlas row). Atlas ≈ +0.2 MB per team.
- **Control.** No new input. Which stockade you hold, and holding still to let archers loose, are the decisions. One-shot hint `polish.hintArcher`.
- **Deferred:** knight, tool racks, counters matrix, front-sorting, per-type HUD counts, bandit archers, fire arrows at stockades, champion unit, mix slider (never).

## 5. Portal-ready pass (M1)

Ships first; changes nothing a player sees. Seven tasks (R4 §6), about 2 h:
1. **Fonts.** `fonts/` with Google's latin variable woff2 for Baloo 2 (33 KB) and Nunito (39 KB), OFL texts, `@font-face` + preload in `style.css`, Google Fonts links removed, `await document.fonts.load` (1.5 s cap) in boot before `loadingStop`, `LICENSES.md` updated.
2. **Adapter.** `portal.js` reads `<meta name="ps-portal">` first, then `?portal=` (local QA), else none. CrazyGames: after `SDK.init()`, `environment === "disabled"` swaps to the no-op adapter. Poki: `init().catch(() => {})`. `commercialBreak(onStart)`: mute via master gain (50 ms ramp, never `ctx.suspend()`) in onStart, unmute on resolve. Platform mute via `game.settings.muteAudio` + `addSettingsChangeListener` overrides M and the sound button. `pause(reason)`: on CrazyGames skip `gameplayStop` for `hidden`/`blur`; window `blur` pauses while playing. Happytime: win only on CrazyGames; Poki `happyTime(0.5)` first rout, `1` win. `PS.portal.store` seam over `SDK.data` / try-catch localStorage.
3. **Ads.** Midgame only on PLAY AGAIN (end screen) and on the title's PLAY after the first match of the session, awaited before `newGame`. Never at the horn, on unpause, or before the first match. No rewarded ads in v3.
4. **Portal build.** `tools/portal-build.mjs crazygames|poki` copies runtime files to `dist/<portal>/`, injects meta + SDK tag, excludes `tools/`, `*.md`, `thumb.jpg`, zips. GitHub Pages copy byte-identical to before.
5. **Adaptive DPR.** On touch keep the DPR-2 zoom step table at every tier (the floor of 0.5 never vanishes). `imageSmoothingEnabled` on for world sprites when zoom × DPR < 1; sprite positions snap to device pixels at the live DPR. Second trigger: rAF interval p90 > 45 ms for 3 s, only after first input. 2 s grace after match start and visibility return. Order of levers: `polish.effectsTier` first (LATER if out of time), DPR second, agent cap last. Remember the tier in localStorage (7-day expiry). `?dpr=1.5`, `?dpr=1` overrides.
6. **Audio hardening.** `resume().catch`, `pageshow`, 1 s frozen-clock watchdog, close-and-rebuild after two failed gestures, master ramp on hidden.
7. **Iframe checks.** Harness at 640×360, 800×450, 907×510, 1216×684 inside an iframe from another port.

Portal choice and submission timing are Peter's (§10).

## 8. Performance

Baseline (M8 hand-off): phone sim p90 2.8 ms at 4× CPU throttle in `PS.bench("capclash")` with the touch cap at 640. Floor 4 ms. Headroom 1.2 ms. Paper sum of R1–R3 is +0.4–0.5 ms at 4×, and the costs cluster early in a match (cold viewshed caches at first ridge sightings, first volleys, stockades leaving grace). Gates in §9 are whole-tick, cumulative, run on the milestone's own tree with every earlier milestone landed. Draw: one `drawImage` per agent; arrows and stockade arrows inside the existing `art.drawOverhead` 90; one full-screen alpha layer; canvas budget stays under 60 MB (v2: 20 MB). Chunk bake with canopy art measured at 4× after a hidden-tab return before M2 closes.
